## Task 3. 继承与代码复用（推荐完成）

继承是面向对象建模的重要方式之一。下面给出一个父类：

```java
public class Animal {
    private String name;
    private int id;

    public Animal(String myName, int myId) {
        name = myName;
        id = myId;
    }

    public void eat() {
        System.out.println(name + "正在吃");
    }

    public void sleep() {
        System.out.println(name + "正在睡");
    }

    public void introduction() {
        System.out.println("大家好！我是" + id + "号" + name + "。");
    }
}
```

请完成以下内容：

<Steps>

1. 创建 <Badge text="Penguin" /> 和 <Badge text="Mouse" /> 两个子类，并继承 <Badge text="Animal" />。
2. 使用 <Badge text="super" /> 调用父类构造方法。
3. 尝试在子类中重写至少一个父类方法，体现不同对象的行为差异。
4. 解释：为什么 Java 不支持类的多继承？

</Steps>
