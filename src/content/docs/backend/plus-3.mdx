### Nginx的结构

简单了解⼀下Nginx的⽬录结构，通常，我们只需要关注html静态资源⽬录与conf配置⽂件即可，根据安装⽅式和操作系统的差异，⽂件存放⽬录可能会有所不同。

你需要重点关注的是http块，每个http块中可以包含多个server块。

### 负载均衡

在搭建⼀个⽹站时，为了避免后端服务器的压⼒过⼤，往往会采取集群部署的⽅式，前端的请求通过负载均衡策略转发到后端的不同服务器上，接下来我们尝试使⽤Nginx模拟这个过程。

💡⼩练习：

- 你需要创建Main01，Main02，Main03三个类，将下⾯代码复制进去，并启动这三个服务。

```java
import com.sun.net.httpserver.HttpServer;
import com.sun.net.httpserver.HttpHandler;
import com.sun.net.httpserver.HttpExchange;
import java.io.OutputStream;
import java.net.InetSocketAddress;
public class Main01 {
    public static void main(String[] args) throws Exception {
        HttpServer server = HttpServer.create(new InetSocketAddress(8001), 0);
        server.createContext("/", new HttpHandler() {
            @Override
            public void handle(HttpExchange exchange) throws java.io.IOException {
                String response = "Hello World! from 8001";
                exchange.sendResponseHeaders(200, response.getBytes().length);
                OutputStream os = exchange.getResponseBody();
                os.write(response.getBytes());
                os.close();
            }
        });
        server.setExecutor(null);
        server.start();
        System.out.println("Server running at http://localhost:8001");
    }
}
```

## Task.02 进阶挑战——搭建个⼈博客（选做）

学到这⾥，你已经有能⼒搭建⼀个⾃⼰的博客了，你可以在⾃⼰的博客上做学习笔记，经验分享，亦或是让更多的⼈认识你。（或者是拿来在同学⾯前装b？）这⾥推荐⼏个快速搭建博客的⽹站

- 访问局域⽹ip？/ 端⼝转发？
