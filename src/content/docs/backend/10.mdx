## 部分三：无侵入的魔法——面向切面编程

有的时候，我们希望记录每一个接口是谁调用的、耗费了多长时间，但**不希望在每个方法里面手动写<Badge text="System.currentTimeMillis()" />这样的重复代码**。你有什么想法吗？你可能会想到上一题中提到的责任链模式和Okhttp的Interceptor。幸运的是，SpringBoot也有类似的设计。不过今天，我们不用它们，让我们换一种方法来试一试。

**面向切面编程（AOP）** 是Spring的核心特性之一。如果说面向对象（OOP）是把业务逻辑按照“对象”切分成一个个模块，那么AOP就是把各个模块中共同需要的非业务逻辑（横切关注点）抽取出来，像一块“切面”一样统一织入到业务代码中。

请了解一下面向切面编程，思考一下，在什么场景下你会推荐使用AOP？它解决了传统面向对象（OOP）编程中的什么痛点？

参考文章：

- [AOP科普版](https://cloud.tencent.com/developer/article/2513231)
- [AOP概念理解](https://liaoxuefeng.com/books/java/spring/aop/index.html)
- [AOP详细讲解](https://zhuanlan.zhihu.com/p/421999882)

接下来就来尝试一下，在你上面的CRUD的代码基础上使用AOP来统一记录一下每次执行方法的耗时，并打印当前请求的URL和HTTP方法（GET、POST等）吧！

请在你的<Badge text="pom.xml" />中添加依赖：

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-aspectj</artifactId>
</dependency>
```

任务要求：

<Steps>

1. 编写一个切面类，用于拦截你的所有Controller接口。注意，此任务中你**不能**直接修改你的Controller代码。
2. 通过你编写的切面类，打印方法执行的耗时，以及当前请求的URL和HTTP方法。
3. 打印方法请使用slf4j，不能使用<Badge text="System.out.println()" variant="danger" />等方法。

</Steps>

以下是一个示例，但仅实现了打印方法执行的耗时。你可以自己从头编写一个切面类，或者修改和补全下面的示例，并把这个实例类放到你的SpringBoot项目中的合适位置。

```java
package com.example.demo.aspect;

import lombok.extern.slf4j.Slf4j;
import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.annotation.Pointcut;
import org.springframework.stereotype.Component;

import java.util.Arrays;

@Aspect
@Component
@Slf4j
public class LogAspect {
    @Pointcut("within(com.example.demo.controller..*)")
    public void logLayer() {}

    @Around("logLayer()")
    public Object logAround(ProceedingJoinPoint joinPoint) throws Throwable {
        String targetClass = joinPoint.getTarget().getClass().getSimpleName();
        String methodName = joinPoint.getSignature().getName();
        Object[] args = joinPoint.getArgs();
        log.info("即将执行{}.{}(), args={}", targetClass, methodName, Arrays.toString(args));
        long startTime = System.currentTimeMillis();
        Object result = joinPoint.proceed();
        log.info("执行结束: {}.{}(), 耗时{}ms, result={}", targetClass, methodName,
                System.currentTimeMillis() - startTime, result);
        return result;
    }
}
```

如果你能够很好地完成以上内容，可以尝试挑战一下（非必须，仅作为加分项）：

使用自定义注解改造你的AOP，并修改你的AOP切面规则：不再拦截所有接口，而是**哪个接口方法加上了你的自定义注解，才为这个接口打印相关日志**。

### 如果你想在后端开发走得更远...

压轴题实现一个简单的CRUD只是**后端体系的起点**。现代服务端工程体系庞大而浪漫，未来如果你想在后端工程开发这条路上继续深耕，这些有趣而强大的工具/技术正等着你去探索：

- **持久层进阶**：从JPA走到底层，去探究**MyBatis/MyBatis-Plus**的灵活性，学习MySQL的底层索引优化与事务处理。
- **高并发与缓存**：为系统加上**Redis**缓存，体验在内存中达到每秒数十万次读写操作的极速。
- **解耦与异步**：引入消息队列（如**RabbitMQ/Kafka**），看看淘宝双十一的秒杀体系是如何靠异步削峰来拯救服务器的。
- **分布式与架构**：走进**Spring Cloud/微服务**与**Docker/Kubernetes**的世界，体会如何像搭积木一样管理成百上千台服务器。

> 不要被庞大的技术体系吓到！**没有任何一个工程师是把它学完了才开始干活的，在项目中动手实践，才是成长最快的方式。**
