## Task 3. 理解一个 Java 程序的基本结构

下面是一段单文件 Java 代码：

```java
package com.Example;

import com.Example.tool.Print;

public class HelloWorld {
    public static void main(String[] args) {
        Test.test();
    }
}

class Test {
    public static void test() {
        Print.print("Hello World");
    }
}
```

请完成以下问题：

<Steps>

1. 这段代码可以大致分成哪几个部分？每个部分的作用是什么？
2. 什么是 包<Badge text="package" />？为什么 Java 项目里经常需要包结构？
3. <Badge text="import" /> 的作用是什么？
4. <Badge text="main" /> 方法为什么能作为程序入口？
5. 在运行程序时，可以给程序传入参数，由main函数的args参数接收，请你更改main函数，使用命令行或者IDEA运行这个程序传入“111 222 333”这三个参数，并在main函数中打印出来。

</Steps>

如果你是第一次接触 <Badge text="package" />，建议边查资料边完成。本题想看到的是能否把一个陌生概念查明白并实际跑通😊
