## 模块二：能量阵列  —— 逻辑门的重构

引导区已启动，但飞船的能量分布完全紊乱。你需要通过重新拨动控制面板上的六种基础逻辑开关，将能量引流到正确的轨道。

在 C/C++ 中，我们有六个基本的位运算符：

| 运算符 | 名称 | 作用说明 |
| :---: | :--- | :--- |
| <Badge text="&" /> | 按位与 | 对应位都为 1 时才为 1，否则为 0 |
| <Badge text="&verbar;" /> | 按位或 | 对应位只要有 1 就为 1，否则为 0 |
| <Badge text="^" /> | 按位异或 | 对应位不同为 1，相同为 0（可以理解为不进位加法） |
| <Badge text="~" /> | 按位取反 | 0 变 1，1 变 0（注意符号位也会翻转） |
| <Badge text="<<" /> | 左移 | 各二进位全部左移若干位，高位丢弃，低位补 0 |
| <Badge text=">>" /> | 右移 | 各二进位全部右移若干位，对无符号数，高位补 0 |

## 模块五：管道穿梭  —— 自动化寻路

反应堆虽然成功重启，但核心数据链被熔断在狭窄的物理管道深处。GLIMMER无法直接连接核心，你必须投放一台微型维修探针机器人——**代号 M.O.U.S.E.**。

管道系统是一个 $4 \times 4$ 的封闭网格（共 16 个节点，编号 0~15）。M.O.U.S.E. 需要从管道起点（节点 0）穿过毁坏堵塞的管线，抵达被星际工程师们戏称为“奶酪”的核心硬件晶片（代号 C.H.E.E.S.E.，位于节点 15）。

由于探针的微型 CPU 内存极小，你**不能使用任何传统的布尔数组来记录访问状态**，所有的地图障碍和探索轨迹必须完全压缩进 <Badge text="int" /> 变量的比特位中！
