## part2_C语言基础

C语言是大多数人学习的第一门计算机语言。我知道很多同学在上大学以前都没有接触过编程，接下来的招新题目都需要使用C语言进行，要求你至少要基本掌握C语言语法。所以我建议你，不要急于完成接下来我给出的题目，而是去找一个完整的网课或者一部详细的电子书，系统的学习并入门C语言，（这里我推荐黑马程序员和翁凯的课程）。我们的招新只有一轮，会一直持续到期中考试前两周才会截止，因此你完全可以拿出一两周的时间先学习C语言再进行更深入的招新题的学习。并且，我希望你在学习第一门语言的过程中，先不要打开AI的代码补全功能，这会很大的降低你的代码熟练度。希望你可以合理的使用AI。

我们刚刚完成了一个打印“hello world”的简单程序，可是如果我们想进行一定的更改（比如打印不同的内容），都要直接修改源代码。通过搜索引擎，你得知这样不仅太过繁琐，而且不利于我们对程序进行测试，在实际应用中也几乎不可行。所以你打算对程序进行一定的改写，使之可以实现**动态交互**。于是你打算进一步学习**变量**、**数组**、**流程控制 - 循环结构**、**流程控制 - 逻辑表达式**等知识。

## part3_函数

在程序设计中，设置函数的核心目的有两点：**代码复用**和**逻辑组织**

> **代码复用**是指通过抽象化特定功能模块为独立单元，实现算法逻辑的"一次定义，多次调用"，从而消除冗余代码并确保功能一致性。**简单来说，就是把常用的操作打包成工具，随用随取。**

> **逻辑组织**是指通过函数边界建立抽象层次结构，将复杂系统分解为高内聚、低耦合的功能模块，实现认知负荷的有效管理。**简单来说，就是把代码按功能分装进盒子（函数），便于后续查找、维护和修改。**

关于什么是函数，我相信你已经有所了解了，在日后的编程中，我们通常不会在主函数中写大段的语句，而是在主函数中调用自己设定的函数，以实现各种功能。包括实际项目当中，也是如此。在这一题当中，你需要学会如何定义一个简单的函数减少代码复用。

下面我们设置一个情景，方便你更好地了解。

小明、小强、小林是某人三项（共有A、B、C三项）的业余爱好者，某次，三人一同参加了某人三项的趣味赛，成绩如下（满分100）：

小明：77 85 91

小强：82 84 84

小林：72 83 100

请你通过平均分和方差的计算，综合考虑后，为三人综合成绩由高到低排序(成绩相等时，对顺序不做要求)。**综合考虑的具体方法为：综合成绩 = 3 * 平均分 - 方差 / 3**;

下面给出仅由一个<Badge text="main()" />函数完成的程序：

```c
#include <stdio.h>

int main(){
  int x1, x2, x3;
  int y1, y2, y3;
  int z1, z2, z3;

  printf("请输入小明的三项成绩（顺序为A B C,以一个空格为间隔）：");
  scanf("%d %d %d", &x1, &x2, &x3);
  printf("请输入小强的三项成绩（顺序为A B C,以一个空格为间隔）：");
  scanf("%d %d %d", &y1, &y2, &y3);
  printf("请输入小林的三项成绩（顺序为A B C,以一个空格为间隔）：");
  scanf("%d %d %d", &z1, &z2, &z3);

  int p1 = (x1 + x2 + x3) / 3;
  int f1 = ((p1 - x1) * (p1 - x1) + (p1 - x2) * (p1 - x2) + (p1 - x3) * (p1 - x3)) / 3;
  int zh1 = 3 * p1 - f1 / 3;
  
  int p2 = (y1 + y2 + y3) / 3;
  int f2 = ((p2 - y1) * (p2 - y1) + (p2 - y2) * (p2 - y2) + (p2 - y3) * (p2 - y3)) / 3;
  int zh2 = 3 * p2 - f2 / 3;

  int p3 = (z1 + z2 + z3) / 3;
  int f3 = ((p3 - z1) * (p3 - z1) + (p3 - z2) * (p3 - z2) + (p3 - z3) * (p3 - z3)) / 3;
  int zh3 = 3 * p3 - f3 / 3;
  
  if (zh1 >= zh2 && zh2 >= zh3) {
      printf("小明 > 小强 > 小林");
  } else if (zh1 >= zh3 && zh3 >= zh2) {
      printf("小明 > 小林 > 小强");
  } else if (zh2 >= zh1 && zh1 >= zh3) {
      printf("小强 > 小明 > 小林");
  } else if (zh2 >= zh3 && zh3 >= zh1) {
      printf("小强 > 小林 > 小明");
  } else if (zh3 >= zh1 && zh1 >= zh2) {
      printf("小林 > 小明 > 小强");
  } else { // zh3 >= zh2 && zh2 >= zh1
      printf("小林 > 小强 > 小明");
  }

  return 0;
}
```

相信你可以看出，在这其中，计算综合成绩（zh）时，代码的重复性非常高；于此同时，输入、计算、排序全过程都在一个函数中完成，不免使得程序看起来过于臃肿。下面，请你参考开始给出的将<Badge text="a + b" />封装成函数<Badge text="int add(int a, int b)" />的示例，**尝试利用自定义函数将<Badge text="main()" />函数的下列内容精简**：
