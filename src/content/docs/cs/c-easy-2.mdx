## Step2. 链操作

### 什么是链表？

链表是一种线性数据结构，它由一组节点组成，每个节点包含数据域和指针域；数据域用于存储元素本身，指针域用于存储下一个节点的地址，从而把各个节点按逻辑顺序连接起来。

### 实现基本的链操作

在我们日后的学习中，各种操作都要围绕**增删改查**进行，接下来让我们实现链操作的增删改查。

你需要将接下来的所有函数放在一个c文件中，并将其上传。

使用你在上一步定义的单向链表节点作为链表节点。链表初始状态为头指针<Badge text="Head" />指向一个data值为0的节点，此时该节点为链表唯一节点。（head -> 0 -> NULL）

#### 添加元素：

在添加元素之前，我们需要先明白，我们添加的元素是什么。链表存储的是**节点而非数据**，因此我们需要先实现一个定义节点的函数。

**请你设计一个函数，传入一个数据（int即可），返回一个存储这个数据的节点。**

如何在链表中插入一个元素呢？我们可以定义一个新的节点A，让A指向头节点0，然后再让头指针指向A，实现**头插**

**请你实现头插函数。函数传入主链表的头指针head和一个数据n**

在实现链表的头插以后，你会自然的想到，能否在链表的尾部插入一个节点。

**请你自己设计尾插函数，并用代码将其实现。（提示：不要直接用头指针，定义一个新的指针将其赋值为头指针）**

#### 查找元素：

如何查找一个元素呢？查找中很多算法，但在这一题当中，你只需要掌握最基本的遍历查找即可。

在数组中，我们想要查找第n位的元素，我们只需要访问arr[n-1]即可。但是在链表中，我们需要依次访问每一个节点，直至访问到第n个节点。依次访问每一个节点，这就是遍历。

**通过遍历思想，我们可以打印链表每个节点的数据。请你实现这个打印链表函数，传入链表头指针。且打印后不要改变头指针的指向。**

通过这个打印函数，你可以先验证上面你添加元素的函数是否正确。

我们更多查找的是，定义一个数据n，查找链表中是否存在一个节点，其存储的数据为n。

**请你实现这个查找函数。传入头节点head和要查找的数据n，输出这个节点距头节点的距离（统计这是第几个节点）。如果有多个数据为n的节点只返回第一个，如果没有查找到则返回false。**

#### 删除和更改：

在查找到某一个特定节点的基础上，通过修改data的值即可实现更改。

那么该如何删除一个节点呢？我们需要引入双指针。两个指针交替向前直到后一个指针指向要删除的节点，前一个指针在要删除节点前。然后让前一个指针指向要删除节点的下一个节点。然后free掉要删除的节点即可。

**请你实现删除第n个节点的函数。只传入头指针和n，如果链表节点数少于n返回false，反之返回true。**

#### 反转函数：

**请根据上面双指针的思想，设计一个函数，传入头指针，然后将链表倒置，头指针指向新链表的第一个节点。**

链操作不止可以用在链表上，其他所有的数据结构都可以采用顺序表和链表两种存储方式。在下一题中我们会学习简单的二叉树，其中就会用到链来存储数据。
