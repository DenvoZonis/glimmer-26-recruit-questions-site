## Step 3. 自定义函数

**函数**是执行特定任务的自包含代码块，是程序的基本构建单元。在C语言中，函数分为**库函数**和**自定义函数**。库函数前面已经有所触及，这里就不赘述了。而自定义函数，就是在实际代码编写中，程序员为了实现库函数无法满足的需求时，自主创建的函数。函数的一般结构如下：

```
返回类型 函数名(参数列表) {
    函数体
}
```

我们可以举一个比较直观的例子：

假设我们的原代码如下：

```c
#include <stdio.h>

int main(){
  int a, b;
  scanf("%d %d", &a, &b);
  printf("%d", a + b);
}
```

为了让代码更清晰、更容易重复使用计算两数之和的功能，我们可以把 a + b 这个计算过程单独定义成一个函数。这个过程可以称之为**将<Badge text="a + b" />封装成函数<Badge text="int add(int a, int b)" />**, 改写后代码如下：

```c
#include <stdio.h>

int add(int a, int b){
  return a + b;
}

int main(){
  int a, b;
  scanf("%d %d", &a, &b);
  printf("%d", add(a,b));
}
```

这就是自定义函数的一个简单实现。当我们运行程序时，程序从主入口（在C语言中，程序的主入口一般情况下都是main 函数）开始执行，遇到自定义函数(如add(a,b))调用时：

<Steps>

1. 暂停当前执行，保存上下文，传递参数；
2. 跳转至函数体内按序执行（可嵌套调用其他函数）；
3. 执行完毕后，返回结果（若有），恢复上下文；
4. 从调用处下一条指令继续执行。

</Steps>

在这里，我们封装的函数对当前代码整体编写的效果并不明显，也就是说，我们在这里定义的<Badge text="add()" />函数，针对当下的程序，其实并不是必要的。那么什么时候封装函数是必要的呢？

在程序设计中，设置函数的核心目的有两点：**代码复用**和**逻辑组织**

> **代码复用**是指通过抽象化特定功能模块为独立单元，实现算法逻辑的"一次定义，多次调用"，从而消除冗余代码并确保功能一致性。**简单来说，就是把常用的操作打包成工具，随用随取。**

> **逻辑组织**是指通过函数边界建立抽象层次结构，将复杂系统分解为高内聚、低耦合的功能模块，实现认知负荷的有效管理。**简单来说，就是把代码按功能分装进盒子（函数），便于后续查找、维护和修改。**

下面我们设置一个情景，方便你更好地了解。

小明、小强、小林是某人三项（共有A、B、C三项）的业余爱好者，某次，三人一同参加了某人三项的趣味赛，成绩如下（满分100）：

小明：77 85 91

小强：82 84 84

小林：72 83 100

请你通过平均分和方差的计算，综合考虑后，为三人综合成绩由高到低排序(成绩相等时，对顺序不做要求)。**综合考虑的具体方法为：综合成绩 = 3 * 平均分 - 方差 / 3**;

下面给出仅由一个<Badge text="main()" />函数完成的程序：

```c
#include <stdio.h>

int main(){
  int x1, x2, x3;
  int y1, y2, y3;
  int z1, z2, z3;

  printf("请输入小明的三项成绩（顺序为A B C,以一个空格为间隔）：");
  scanf("%d %d %d", &x1, &x2, &x3);
  printf("请输入小强的三项成绩（顺序为A B C,以一个空格为间隔）：");
  scanf("%d %d %d", &y1, &y2, &y3);
  printf("请输入小林的三项成绩（顺序为A B C,以一个空格为间隔）：");
  scanf("%d %d %d", &z1, &z2, &z3);

  int p1 = (x1 + x2 + x3) / 3;
  int f1 = ((p1 - x1) * (p1 - x1) + (p1 - x2) * (p1 - x2) + (p1 - x3) * (p1 - x3)) / 3;
  int zh1 = 3 * p1 - f1 / 3;
  
  int p2 = (y1 + y2 + y3) / 3;
  int f2 = ((p2 - y1) * (p2 - y1) + (p2 - y2) * (p2 - y2) + (p2 - y3) * (p2 - y3)) / 3;
  int zh2 = 3 * p2 - f2 / 3;

  int p3 = (z1 + z2 + z3) / 3;
  int f3 = ((p3 - z1) * (p3 - z1) + (p3 - z2) * (p3 - z2) + (p3 - z3) * (p3 - z3)) / 3;
  int zh3 = 3 * p3 - f3 / 3;
  
  if (zh1 >= zh2 && zh2 >= zh3) {
      printf("小明 > 小强 > 小林");
  } else if (zh1 >= zh3 && zh3 >= zh2) {
      printf("小明 > 小林 > 小强");
  } else if (zh2 >= zh1 && zh1 >= zh3) {
      printf("小强 > 小明 > 小林");
  } else if (zh2 >= zh3 && zh3 >= zh1) {
      printf("小强 > 小林 > 小明");
  } else if (zh3 >= zh1 && zh1 >= zh2) {
      printf("小林 > 小明 > 小强");
  } else { // zh3 >= zh2 && zh2 >= zh1
      printf("小林 > 小强 > 小明");
  }

  return 0;
}
```

相信你可以看出，在这其中，计算综合成绩（zh）时，代码的重复性非常高；于此同时，输入、计算、排序全过程都在一个函数中完成，不免使得程序看起来过于臃肿。下面，请你参考开始给出的将<Badge text="a + b" />封装成函数<Badge text="int add(int a, int b)" />的示例，**尝试利用自定义函数将<Badge text="main()" />函数的下列内容精简**：

2. 利用自定义函数，将三人的综合成绩计算的过程进行封装。（代码复用）

3. 将综合成绩的排序，利用自定义函数进行封装。（逻辑组织）

</Steps>
