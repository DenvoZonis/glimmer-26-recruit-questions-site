## **故事背景：**

muramasa喜欢打瓦罗兰特，更喜欢看瓦罗兰特的比赛，瓦罗兰特最近举办了一年一度的冠军赛，muramasa和他的室友们都很期待。

在muramasa给出的一系列瓦罗兰特战队中，他和他的室友各有各自支持的战队：

室友1: 从第一个战队开始，只支持战队排序中序号为奇数的战队。

室友2: 只支持排序倒数第三低的战队。

室友3:只支持class为EDG的战队。

室友4:在前三个室友支持完后, 支持票数最高且排序最前的战队。

## **任务：**

开始答题前，需要先下载本题的项目代码文件夹，目录结构如下：

```txt
├── css
│   └── style.css
├── images
└── index.html
```

其中：

- `index.html` 是主页面，需要你在index中补充代码。
- `css/style.css` 是样式文件。
- `images` 是图片文件夹。

请在 `index.js` 文件中补全`<script> </script>`中的代码，使得：

- 统计每个战队被支持的票数
- 在按下`开始支持投票`按钮后，各个战队根据获得的票数(n)，向右移动n×100px。
- 按下`开始支持投票`按钮后，将得票数最多的战队的class在网页下方**使用动画**显现出来
- 注意：统计支持票数、战队图标右移、class显现这几个步骤**只能用jQuery的功能实现。**

## **可能遇到的问题**

- 注意此题虽然样本中只有四个战队，但是实际测试时的数据可能有更多战队，排序也会改变，所以你需要编写出具有泛用性的代码。

- 如何利用jQuery选取DOM节点，如何实现简单动画？

- 上网找一些jQuery教程
