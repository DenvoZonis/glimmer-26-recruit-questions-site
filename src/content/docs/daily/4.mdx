## 再学会远程仓库🗝️

	* 注册[GitHub](https://github.com/)或[Gitee](https://gitee.com/)账号
	* 创建远程仓库
	* 将远程仓库克隆到本地
	* 将代码上传至远程仓库

> 如果你只是想体验一遍使用git的流程，可以先把本地提交做好，再把本地仓库推到远程仓库。

### 相关命令行

#### 创建远程仓库

如果你用的是 GitHub CLI，可以直接使用命令行创建仓库：

先在你项目对应的文件夹下点击鼠标右键打开 Windows 终端，再执行下面的命令即可。

```bash
gh auth login
gh repo create 你的仓库名 --public --confirm
```

如果你已经有一个本地项目，并且想顺手创建远程仓库、绑定远程地址并推送第一次提交，也可以这样：

```bash
gh repo create 你的仓库名 --public --source=. --remote=origin --push
```

#### 将远程仓库克隆到本地

```bash
git clone https://github.com/用户名/仓库名.git
```

#### 将代码上传至远程仓库

```bash
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/用户名/仓库名.git
git push -u origin main
```

如果远程仓库已经绑定过了，后面更新代码一般只需要：

```bash
git add .
git commit -m "update"
git push
```


## 小结

- Git 不是单纯的“上传工具”，它更像是帮你管理代码变化历史的工具
- 本地仓库解决的是“怎么保存和回退”，远程仓库解决的是“怎么协作和同步”
- 先把基本流程跑顺，再去理解分支和冲突，会更容易上手
