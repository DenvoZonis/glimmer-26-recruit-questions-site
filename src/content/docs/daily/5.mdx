## 基本概念

- AI Agent：通常指将大型语言模型（LLM）与外部能力（如搜索、文件读写、终端命令、HTTP 请求等）组合起来，能够“感知环境、计划步骤并执行工具”的系统。💡
- Tool（工具）：Agent 可调用的外部能力，比如 <Badge text="search()" />, <Badge text="read_file()" />, <Badge text="run_command()" />。
- Chain-of-thought（思路链）：让 Agent 输出推理步骤，有助于可解释性，但在生产环境需谨慎使用以免泄露内部信息。

## 常见 Agent 类型与示例

- 聊天型（Chatbot）：以对话为中心，适合问答、咨询场景。
- 检索增强生成（RAG）：先检索相关文档，再由 LLM 生成答案，适合知识库问答。
- 工具调用型：模型决定何时调用外部工具并处理返回结果，适合需要执行动作的场景（下订单、执行脚本）。

## 使用策略与 Prompt 设计

2. 给出示例：提供 1-2 个输入输出示例，帮助模型遵循格式。

</Steps>

示例 Prompt（提纲生成）：

> 你是一个写作助手。你的任务是根据用户给出的主题，生成一份文章提纲。
>
> 输出格式：
> - 只输出提纲，不要解释过程。
> - 每个要点单独一行，使用“1. 2. 3.”编号。
> - 回答要点式列出，不超过 6 行。

## 权限与安全注意事项

- 最小权限原则：为 agent 授权时只开放必要能力（e.g.只读文件、禁止随意发起网络请求）。
- 隐私保护：不要在 prompt 或工具返回中包含敏感信息（e.g.密码、私钥、个人隐私）。
- 日志与审计：保留工具调用记录以便事后审查，但在保存日志前去除敏感字段。
- 验证与确认：对会引起实际更改的操作（e.g.删除文件、发送请求）要求二次确认或人工审批。
